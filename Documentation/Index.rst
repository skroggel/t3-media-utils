===========
Media Utils
===========

:Extension key:
   media_utils

:Package name:
   madj2k/t3-media-utils

:Version:
   14.4.2

:Language:
   en

:Author:
   Steffen Kroggel

:License:
   GPL-2.0-or-later

----

Media Utils provides configurable responsive images, reusable media partials
and Fluid ViewHelpers for TYPO3 projects.

The extension is intended for site packages, content blocks, Fluid templates
and custom extensions that need consistent image and media rendering.
